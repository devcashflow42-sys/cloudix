Cloudix API

Backend de red social sobre Cloudflare Pages Functions + PostgreSQL (Neon).

La API vive bajo /auth, /users, /posts, /comments, /reactions, /stories, /follows, /groups, /communities, /messages, /notifications, /search, /upload y /admin.

Estado del servicio: GET / (función functions/index.js).

Esta página estática existe para que Cloudflare Pages tenga un directorio de salida (public/) que publicar.
